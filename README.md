# Pokédex

A fast and lightweight Pokédex app for Android, built entirely with Jetpack Compose. Designed for simplicity, it gives you instant access to essential info like Pokémon types, evolution lines, move stats, and item effects in one clean interface.

## Data Source

All Pokémon data, including stats, moves, items, and evolutions, is consumed from the [PokéAPI](https://pokeapi.co/).

## Tech Stack & Libraries

This project is built using modern Android development tools and architectural patterns:

* **UI:** Jetpack Compose (1.5.0), Material Design
* **Architecture & Navigation:** Navigation Compose
* **Dependency Injection:** Koin
* **Networking:** Retrofit2, OkHttp3
* **Serialization:** Gson
* **Image Loading:** Coil
* **Local Storage:** DataStore Preferences

## Installation

You can install the app directly on your Android device without building it from source by downloading the latest release.

1. Navigate to the [Releases](https://www.google.com/search?q=https://github.com/arix2000/Pokedex/releases) page of this repository.
2. Download the latest `.apk` file directly to your Android device.
3. Open the downloaded `.apk` file. (Note: You may be prompted to allow **Install unknown apps** from your browser or file manager in your Android settings).
4. Tap **Install** and launch the app.
